# Камеры и POI для навигации BMW MK4

Инструменты для карт BMW MK4 (Siemens VDO / Continental CARiN, например `BMW Road Map Europe EAST 2019`):

- `speedcamgen` — скачивает базу стационарных камер с speedcamonline.ru и делает `output/poison.txt`;
- `poipatch` — записывает камеры прямо в извлечённый образ DVD. Работает на macOS/Linux/Windows,
  Windows-утилита POISoN Patcher больше не нужна.

## Быстрый старт

```sh
make                                   # собрать bin/speedcamgen
go build -o ./bin/poipatch ./cmd/poipatch
./bin/speedcamgen --config ./configs/speedcamgen.yaml
./bin/poipatch -iso ../iso -points ./output/poison.txt
```

`-iso` — папка с содержимым диска (в ней лежат `DB/`, `TPD/`, `ABSTRACT` ...).
**Работайте с копией**: DB_1 перезаписывается на месте.

После патча соберите образ заново и запишите на DVD-R DL. Меняются только
`DB/DB_1` и `TPD/*/ENG/TABLES/0/{0009.IDX,0010.URL,0013.IDX,0014.URL}`, поэтому
проще всего открыть исходный ISO (UltraISO, xorriso) и заменить эти пять файлов.

## Что делает poipatch

1. **Встроенный слой POI карты** (`DB/DB_*`). Камеры пишутся в категорию 28
   («military base») — так же, как POISoN. Её пункт меню занимает слот «city centre».
   Для звукового предупреждения нужна пропатченная программа навигации (patch.exe из POISoN) — её poipatch не трогает.
   Остальные ~2.8 млн POI сохраняются как есть.
2. **Таблицы путеводителя TPD** (`ENG/TABLES/0/0009-0010`, `0013-0014`) — камеры в поиске POI («SPEEDCAM»).

Полезные флаги:

| флаг | что делает |
| --- | --- |
| `-dry-run` | только показать статистику и что будет сделано |
| `-export file.txt` | выгрузить камеры, которые сейчас на диске, в формате poison.txt |
| `-no-tpd`, `-no-db` | не трогать таблицы TPD / слой POI |

Формат входного файла: `долгота,широта` в градусах WGS84, по строке на точку.

Повторный запуск на уже пропатченном диске заменяет старые камеры, DB_1 не растёт (режим *replace*).
На чистом диске слой пишется в конец DB_1 (режим *append*).

## Проверки

```sh
go test ./...                                   # таблицы TPD
CARINDB_TEST_DIR=../iso/DB go test ./pkg/carindb # сверка с реальным диском
```

Тесты `carindb` проверяют, что разбиение слоя на блоки совпадает с тем, что пишет POISoN,
байт в байт (с точностью до порядка равных записей), и что повторная запись даёт тот же размер DB_1.

Описание форматов — в [docs/FORMAT.md](docs/FORMAT.md).
