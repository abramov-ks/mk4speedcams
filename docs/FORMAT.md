# Форматы диска BMW MK4 (CARiN, Siemens VDO / Continental)

Разобрано на диске `BMW Road Map Europe EAST 2019` (CD-ID 21735, HERE 2017Q4) и по коду
`poison.exe` (POISoN Patcher 1.0, 2009). Все числа big-endian.

## Файлы DB

`DB/DB_0 … DB/DB_3` — одна база, разбитая на файлы < 2 ГБ. Сектор 512 байт.

**ID блока** (u32): `[31..30] номер файла | [29..8] сектор в файле | [7..0] длина в секторах`.

**Заголовок блока** (8 байт): `u32 ID (сам себя) | u16 тип | u8 упаковка | u8 размер распакованного в секторах`.
Упаковка: 0 — нет, 2/15 — zlib, 3 — zlib + дельта-фильтр, 1/14 — собственный формат (не поддерживается).

**Каталог таблиц** — DB_0, смещение `0x21C`, 25 записей по 16 байт:
`u16 id | u16 0 | ID lookup | ID первый блок | ID последний блок`.

Блоки одной таблицы лежат подряд: следующий блок начинается с сектора `sector + length`.

## Координаты слоя POI и TPD

`x = (lon + 30) * 5e7/9`, `y = lat * 5e7/9` (≈ 2·10⁹ единиц на 360°, долгота сдвинута на 30°).

## Блок описания карты (dataset, тип 7)

ID из таблицы 7 (`0x00000304`), не упакован.

| смещение | что |
| --- | --- |
| 0x08 | 3 × (u16 offset, u16 count) — секции |
| 0x14 | слои по 28 байт: `ID lookup, x1, y1, x2, y2, 8 байт флагов`; слой 0 — карта, **слой 1 — POI** |
| секция 0 | меню категорий POI: записи по 6 байт, первое u16 — код категории |

POISoN записывает новый ID lookup в слой 1 (`0x30`) и, если категории 28 нет в меню, ставит её на место 48 («city centre»).

## Слой POI

Сетка `512 × 512` ячеек по `0x300000` единиц от угла (x1, y1) слоя. Номер ячейки `cx * 512 + cy`.

**Первичный lookup (тип 8)** — цепочка блоков по 48 секторов подряд:
`+8 u16 offset(0x10) | +10 u16 count | +12 u32 размер ячейки | u32 ID вторичного блока × count` (0 — пустая ячейка).
В полном блоке 6140 ссылок, всего 262144.

**Вторичный lookup (тип 9)** — один на непустую ячейку:

| смещение | что |
| --- | --- |
| +8  | u16 `0x14` — начало сетки квадов |
| +10 | u16 `n²` — число квадов (n = 1, 2, 4, 8 …) |
| +12 | u16 смещение ссылок (`0x14 + 2n²`, выровнено до 4) |
| +14 | u16 число ссылок |
| +16 | u32 размер квада (`0x300000 / n`) |
| 0x14 | u16 × n² — для квада (qx·n + qy) смещение его ссылки в этом блоке, 0 — пусто |
| …   | u32 × k — ID блоков точек, по порядку (x1, y1) их прямоугольников |

**Блок точек (тип 6)**: `+8 u16 0x20 | +10 u16 count | +12 u32 0 | +16 x1 y1 x2 y2`, с `0x20` записи по 28 байт, затем строки имён (одинаковые имена хранятся один раз).

Запись точки:

| смещение | что |
| --- | --- |
| 0  | u32 — ссылка на данные (у точек POISoN 0) |
| 4  | u16 |
| 6  | u16 `(x - x1) >> 6` |
| 8  | u16 `(y - y1) >> 6` |
| 10 | u16 категория |
| 12 | u16 смещение имени в блоке, 0 — без имени |
| 14 | u16 |
| 16 | u32 |
| 20 | 8 байт 0 |

Записи отсортированы по x.

**Разбиение ячейки**: если точки не помещаются в блок 24576 байт (48 секторов), область делится пополам — сначала по y, потом по x, и так поочерёдно, пока каждая часть не поместится. Сетка квадов — `2^ceil(глубина/2)` на сторону.

**Размещение**: блоки слоя POISoN пишет в конец последнего файла DB: первичные, потом вторичные, потом блоки точек.
Если слой уже лежит в конце (прошлый запуск), файл обрезается до его начала и слой пишется заново (*replace*), иначе дописывается (*append*).

## TPD (путеводитель, Mapscape)

`TPD/<продукт>/INFO.PSC`, `<LANG>/<LANG>.LSC` (категории, иконки, формы поиска), `SE/SF_xxxx.HTM` (форма поиска
ссылается на пару таблиц), `TABLES/0/*.IDX` + `*.URL`. Кодировка ISO-8859-1.

URL: строка `<cat>URL-<form>\r\n`, строка полей `POSWGS:S:20|NAME:S:8|NT:S:1\0\r\n`, записи фиксированной
длины, дополненные `\0`, каждая с `\r\n`. POSWGS — текст `"x,y"`.

IDX: `Glambda- <cat>IDX-<form>_\r\n`, `ID:I:<w>|POS:P:8|SELNAME:S:n|NAME:S:n\r\n`, строка разреженного индекса
(`4×\0 + x(0)`, затем `| + u32 номер + x(номер)` каждые 20–50 записей, `\0\r\n`), записи: номер (выровнен вправо),
8 байт POS (u32 x, u32 y), SELNAME, NAME, `\r\n`. POS двоичный и может содержать `\r`/`\n` — читать по длине записи.
Таблица отсортирована по x.

Камеры на этом диске: категория 15 (`SF_0015` → `0013.IDX/0014.URL`), 13 (`0009/0010`, та же копия), 14 MobilCam (`0011/0012`).
